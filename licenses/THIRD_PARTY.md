# Third party components added in v0.0.5

- Sora Editor 0.23.4 (https://github.com/Rosemoe/sora-editor), LGPL 2.1. Used as a normal library through Gradle.
  Sentia talks to it only through `ui/CodeEditorView.java` and `ui/EditorEngine.java`.
- TextMate grammars for Java, XML, HTML, CSS, JavaScript, JSON and Markdown: from Visual Studio Code
  (https://github.com/microsoft/vscode, MIT) and the Sora Editor sample project.
- Editor colour themes `quietlight` and `darcula` (assets/textmate): from the Sora Editor sample project.
- JetBrains Mono (https://github.com/JetBrains/JetBrainsMono), SIL Open Font License 1.1, see OFL-JetBrainsMono.txt.
